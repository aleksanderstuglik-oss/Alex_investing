About Folio

Folio is a clean, no-nonsense portfolio tracker built to help investors monitor their stock holdings, visualise allocation, and track returns over time.

The backend is powered by Python + FastAPI + yfinance, fetching live prices from Yahoo Finance. The frontend is pure HTML, CSS, and JavaScript — no frameworks, no dependencies, loads instantly.
